# Why Does Uncertainty Feel Like Chemistry? — Remotion episode

A complete, source-only Remotion project for a 127.43-second "Awaken"-style explainer
episode for **Pakka Stories**. Everything on screen is drawn in SVG/React and everything
in the soundtrack is generated by the scripts in this repository — there are no stock
assets, no downloaded footage, and no burned-in subtitles.

| | |
|---|---|
| Composition | `AwakenEpisode` (entry `src/index.ts`) |
| Resolution | 1920 x 1080, 16:9 |
| Frame rate | 30 fps |
| Length | **3823 frames** = 127.43 s (body 3733 + separate 90-frame outro) |
| Narration | 28 lines, male English TTS, placed on the scripted cue timestamps |
| Music | 5 original movements, sidechain-ducked **-9 dB** under speech |
| SFX | 87 frame-accurate cues drawn from 15 generated effects |
| Subtitles | off (deliberate — on-screen text is diegetic/HUD only) |

---

## 1. Quick start

```bash
npm install

# 1:1 preview (half resolution, CRF 28, ~5-7 min on 2 cores)
npm run preview

# open an interactive studio
npm run start
```

## 2. The final render command

This is the exact command that produces the delivery master. It is deliberately **not**
run by this project yet — the preview is the last artefact that gets built without
sign-off.

```bash
npx remotion render src/index.ts AwakenEpisode out/final-video.mp4 \
  --codec=h264 \
  --crf=18 \
  --concurrency=2 \
  --pixel-format=yuv420p \
  --x264-preset=slow \
  --audio-codec=aac \
  --audio-bitrate=320k
```

`npm run build` runs the same render with a shorter flag list
(`--codec=h264 --crf=18 --concurrency=2`).

If Chromium cannot be downloaded in your environment, point Remotion at an existing
browser binary:

```bash
npx remotion render src/index.ts AwakenEpisode out/final-video.mp4 \
  --codec=h264 --crf=18 --concurrency=2 \
  --browser-executable=/path/to/chrome --chrome-mode=chrome-for-testing
```

## 3. Project layout

```
episode/
  script.txt              the 28 timestamped lines (source of truth, verbatim)
  episode.json            generated cue/scene/music/SFX score (do not hand-edit)
  narration-timing.json   measured start/end frame of every spoken line
src/
  index.ts, Root.tsx      Remotion entry + composition registration
  EpisodeMaster.tsx       scene sequencer + audio layer
  types.ts                Episode / Scene / Cue / widget contracts
  design/                 colour tokens and local @fontsource loading
  motion/anim.ts          springs, easing, deterministic helpers
  motion/InfographicWidgets.tsx   40+ authored widgets (chalk board, phone, meters, ...)
  characters/             silhouette-head vector puppets (rig + wardrobe + expressions)
  backgrounds/            EnvironmentStage: 22 art-directed environment presets
  camera/CameraRig.tsx    push-in / pull-back / handheld camera presets
  transitions/            whip pan, rack focus, dip, slide transitions
  typography/             screen-space HUD (badges, pills, day markers)
  audio/ducking.ts        narration windows + -9 dB sidechain envelope
  audio/AudioDirector.tsx three-layer soundtrack (narration / music / SFX)
  outro/OutroCard.tsx     the separate 3-second end card
scripts/
  compose-episode.mjs     script.txt -> episode.json (28 cues, 24 scenes, 87 SFX)
  generate-sfx-wavs.mjs   synthesises the 16 SFX WAVs
  generate-music.mjs      synthesises the 5 music movements
  build-narration.mjs     slices the TTS takes into 28 lines on their cue frames
  validate-episode.mjs    30 automated content/asset/audio assertions
  check-preview.mjs       inspects the rendered MP4 (streams, frames, A/V offset)
  plot-audio.mjs          writes dist/audio-check.png (waveform + ducking proof)
  contact-sheet.mjs       tiles rendered stills into review sheets
  package-project.mjs     builds dist/pakka-stories-uncertainty-episode.zip
public/
  audio/narration.wav     final mixed narration stem (28 lines, 127.43 s)
  audio/narration/        per-line stems + source TTS takes + timing metadata
  audio/music/            5 movements, 192 kbps MP3
  audio/sfx/              16 generated WAV effects
  fonts/                  8 woff2 files (Inter, Montserrat, Caveat)
```

## 4. Rebuilding the soundtrack from scratch

```bash
node scripts/compose-episode.mjs        # regenerate episode.json from script.txt
node scripts/generate-sfx-wavs.mjs      # 16 WAV effects
node scripts/generate-music.mjs         # 5 movements (WAV), then encode to MP3 if desired
node scripts/build-narration.mjs        # decode takes -> 28 aligned lines -> narration.wav
```

`build-narration.mjs` expects the three TTS takes in
`public/audio/narration/source/chunk_{0,1,2}.mp3` (cues 0-9, 10-18, 19-27). It decodes
them, finds silence gaps, assigns one gap-bounded segment per scripted line with a
dynamic-programming pass, time-fits only the lines that would otherwise collide (≤1.30x,
no pitch shift), lays every line exactly on its cue start, and writes both
`public/audio/narration.wav` and the timing map the ducking envelope reads.

## 5. Verification

```bash
npm run typecheck          # tsc --noEmit
node scripts/validate-episode.mjs   # 30 content + asset + audio assertions
node scripts/check-preview.mjs      # inspects out/preview.mp4
node scripts/plot-audio.mjs         # dist/audio-check.png
```

## 6. Notes and constraints

* **Subtitles stay off.** `episode.subtitles === false`; `EpisodeMaster` has an explicit
  comment where a caption track would go. Readable on-screen text is diegetic chalk or a
  HUD badge, never the narration transcript.
* **The outro is a separate segment** (S24, frames 3733-3822, 90 frames = 3.0 s) with its
  own card, its own music tail and its own riser — it is not part of the narration body.
* **Fonts are local.** Google Fonts is not reachable from every render machine, so the
  eight woff2 files live in `public/fonts` and are registered through `@remotion/fonts`.
* **`archive/village-story/`** is an earlier, unrelated project kept in place. It is not
  part of this episode and is excluded from the delivered ZIP.
* Deterministic: every animation is a pure function of `useCurrentFrame()`; there is no
  Math.random, no CSS animation, no timer. Re-rendering the same frame twice produces
  the same pixels.
